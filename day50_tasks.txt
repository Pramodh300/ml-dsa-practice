1. Underfitting
What is it?
The model is too simple — it fails to learn the pattern even from training data.
Signs:

Low training accuracy
Low test accuracy
High bias

Causes:

Model is too simple (e.g., using Linear Regression on non-linear data)
Too few features
Too little training time / iterations

Visual:
Data points: * * * * * * *
Model line:  _______________  ← straight line, misses the curve completely
Fix:

Use a more complex model
Add more relevant features
Train longer / more epochs


2. Overfitting
What is it?
The model is too complex — it memorizes the training data including its noise, and fails on new data.
Signs:

Very high training accuracy
Low test accuracy
High variance

Causes:

Model is too complex (too many layers, too many parameters)
Too little training data
Training for too long

Visual:
Data points: * * * * * * *
Model line:  ~∿~∿~∿~∿~∿~  ← wiggles through every point, even noise
Fix:

Regularization (L1/L2) — penalizes model complexity
Dropout — randomly switches off neurons during training (Deep Learning)
More training data
Early stopping — stop training when validation loss starts rising
Cross Validation — detect it early (Day 49!)
Pruning — for Decision Trees

Detecting Overfitting/Underfitting in Python
pythonfrom sklearn.linear_model import LinearRegression
from sklearn.preprocessing import PolynomialFeatures
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error
import numpy as np

# Sample data
X = np.array([[i] for i in range(20)])
y = np.array([2*i + np.random.randn() for i in range(20)])

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

model = LinearRegression()
model.fit(X_train, y_train)

train_score = model.score(X_train, y_train)
test_score  = model.score(X_test, y_test)

print(f"Train Accuracy: {train_score:.2f}")
print(f"Test Accuracy:  {test_score:.2f}")

# If train >> test  → Overfitting
# If both are low   → Underfitting
# If both are close and high → Good model ✅

Regularization (Quick Look)
L1 (Lasso) — can zero out features completely
pythonfrom sklearn.linear_model import Lasso
model = Lasso(alpha=0.1)  # alpha controls penalty strength
L2 (Ridge) — shrinks all feature weights
pythonfrom sklearn.linear_model import Ridge
model = Ridge(alpha=1.0)

Higher alpha → stronger regularization → simpler model → less overfitting
